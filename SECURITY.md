# Security

Smart Cleanup is **dry-run by default**. Review what it finds before using `--live`.

Keep real Deluge passwords, VPN credentials, API keys, tokens, private tracker details and private paths out of files you publish or share.

When live mode is enabled, the tool can remove torrents and, depending on your settings, downloaded data. Test your configuration first and keep backups of anything important.

If you find a security issue, please use GitHub's private vulnerability reporting or security advisory feature when available instead of posting sensitive details in a public issue.
